# Home page: customer results videos in place of the athletes block

`theme/templates/index.json` is the home page template from the preview theme (203974869339) with the
"Still training. Still working. Not done yet." athletes section (`muto-home-athletes`) replaced, in the
same position, by the product page's "Don't take our word for it." customer results videos
(`muto-home-results`, the `results` section of `product.muto-nad-bf.json`, all 8 videos and settings).
Nothing else on the home page changed. `live-snapshot/` holds the files it was built from.
