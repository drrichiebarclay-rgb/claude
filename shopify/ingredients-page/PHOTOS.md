# Ingredient photos: where each ingredient comes from

The ingredient library shows a photo per ingredient when one is set (theme editor → Ingredients page →
MUTO Ingredient library → the ingredient's block → Photo). Until then it draws a stand-in.
Every photo gets the same soft grade automatically (section setting "Soft grade on ingredient photos"),
so stock from different sources reads as one set, as on Diome.

**Brief for every shot:** square, close and tactile, natural light, one subject filling most of the frame,
plain or soft background, no hands holding supplements, no text. Unsplash and Pexels photos are free for
commercial use; check each photo's licence page before using it.

| Ingredient | Where it comes from: what to shoot or search |
|---|---|
